# Florida Kimono — Outreach Program

Goal: build community and increase outreach to people who don't yet know the Florida Kimono Club exists, starting with the Orlando Asian-American and Japanese-culture community.

## How this works

- **`tracker.md`** — the master list of people and businesses to write to, one row per contact, with status.
- **`Florida_Kimono_Outreach_Tracker.xlsx`** — the same tracker as a spreadsheet with dropdowns and an auto-calculating dashboard, for working offline or in Excel/Google Sheets.
- **`templates/`** — reusable outreach message drafts.

## Status definitions

| Status | Meaning |
|---|---|
| Not Contacted | Identified as a target, no outreach sent yet |
| Contacted | First email/call/message sent, awaiting reply |
| Follow-up Needed | They responded or went quiet; a next action is due |
| Meeting Scheduled | A call, coffee, or event meetup is booked |
| Partnered | Active collaboration (event listing, cross-promotion, co-hosted event) |
| Declined / Not a Fit | Pursued and closed out |

## Workflow

1. Add new targets to `tracker.md` (and the xlsx if you use it) as soon as you identify them.
2. Before writing to anyone, verify their contact info on their own website — public listings go stale.
3. Send outreach using a template from `templates/`, personalized for the recipient.
4. Update the Status and Next Action columns after every touch.
5. Follow up after ~2 weeks of silence, once; then mark Declined / Not a Fit if no response after a second follow-up.
